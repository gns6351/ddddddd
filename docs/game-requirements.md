# 거울상담소 요구사항 점검표

「거울상담소 중간보고서」의 요구사항과 서버 구현·검증을 대조한 표입니다. 테스트 이름은 `tests/game.test.js`의 것입니다.

**상태 표기**
- **자동 통과**: 모의 AI 또는 가짜 Gemini 클라이언트로 자동 테스트가 통과함.
- **실제 모델 필요**: 코드는 있지만 수치 목표는 실제 Gemini로 돌려야 확인됨(이 저장소에는 API 키가 없음).
- **앱 필요**: Android 앱 화면이 있어야 확인됨(아직 미착수).

| 방식 | 명령 | 지금 상태 |
|---|---|---|
| 자동 테스트 | `npm test` | 게임 25개 + 기존 회귀 31개 통과(모의 AI) |
| AI 페르소나 시뮬레이션 | `npm run game:sim -- --games 30` | 모의 모드로 끝까지 동작 확인. 실제 Gemini 실행은 아직 안 함 |
| 위험 발화 사례 | `npm run game:risk` | 모의 모드: 직접 20/20, 간접 0/20(모의 AI는 간접 표현을 판단하지 못함) |
| 제작자 교차 플레이 | Android 실기기 | 앱 필요 |

## 명세에 없어서 정한 것

- 보관 기간 30일(`content/game/game.json`의 `consent.retention_days`). 임시값이라 제작자가 정해야 합니다.
- 판당 60회 중 4회는 거울 장면용으로 남겨 둡니다.
- 끝난 미동의 세션은 10분 뒤 메모리에서 지웁니다.
- 상담 턴 요청에 턴 번호를 받습니다(늦게 온 중복 입력 방지).
- 세션은 만든 플레이어(`x-player-id`)만 접근합니다.
- 비교·판단의 수정 문장에도 위험 규칙을 적용합니다.
