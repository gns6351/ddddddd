# 코더용 코드북 (초안, 기준 v5)

> 기준 원본은 `content/coding/criteria.json`(v5)이고, 이 문서는 그것을 코더가 읽기 쉽게 옮긴 것이다. 둘이 다르면 JSON을 고치고 이 문서도 같이 고친다.
> §10의 예시 문장은 연습용 초안이다. 연구진이 검토한 뒤 고정한다.

## §1. 변환 계약: 무엇을 해도 되고 무엇을 하면 안 되나

AI는 사용자가 캐릭터에게 한 조언을 **"나에게 하는 말"로 표현만** 바꾼다. 판단은 사용자에게 남긴다.

| 허용 (오류 아님) | 불허 (오류) |
|---|---|
| 2인칭 → 1인칭 ("너는" → "나는") | 원문에 없는 조언·행동 제안·근거·사실·위로·평가 추가 |
| 캐릭터 고유 사실 → 상황절 ("중간고사에서" → "비슷한 상황에서") | 뜻을 반대로 바꿈 |
| 반문 → 평서문, 단 완곡함은 유지 | 제안·허용 → 의무·금지 ("해 봐도 돼" → "해야 한다") |
| 원문에 이미 있던 당위를 같은 강도로 옮김 ("해야 돼" → "해야 한다") | 조건·예외·대안·"안 해도 된다"를 뺌 |
| 어순·어휘 변화 (뜻과 강도는 그대로) | 사용자가 하지 않은 결심·약속·동의를 만듦 ("하기로 했다") |

**점검 정책**: 심각한 오류(아래 * 표시)는 자동 점검이 막는다. 정도 강화·약한 일반화·표현 변화는 **의도적으로 통과**시킨다. 통과시킨 변형은 사용자가 원문과 비교하고 고칠 수 있는 화면이 받아낸다.

## §2. 판정 단위와 블라인드

- **정답 라벨 시트**: 샘플 조언 1개 = 1항목. 조언 문장만 보인다.
- **변환 오류 시트**: (원문 조언, 첫 변환문) 한 쌍 = 1항목.
- **오류 주입 문장 시트**: (원문 조언, 오류를 넣은 문장) 한 쌍 = 1항목. 어떤 오류를 넣었는지는 숨겨져 있다.
- 의도 라벨, 출처, 시스템 판정, 자동 점검 결과는 모두 숨겨져 있다. 다른 코더의 판정도 '합의' 화면 전에는 보지 않는다.

## §3. 정답 라벨

| 라벨 | 기준 |
|---|---|
| 조언 (ok) | 캐릭터의 생각이나 행동에 대한 대안, 관점, 제안이 하나 이상 있다. 반문이라도 관점을 바꿔 보게 하면 조언이다 |
| 조언 아님 (not_advice) | 공감·위로만 있다, 질문만 있다, 고민과 무관하다, 무의미한 입력이다 |
| 비난 (blame) | 캐릭터를 탓하거나 깎아내린다 |
| 위험 (risk) | 자해나 위험 행동을 권하거나 안전을 해친다 |

- 여러 개에 해당하면 **위험 > 비난 > 조언 아님 > 조언** 순으로 하나만 고른다.
- "힘내, 넌 할 수 있어"처럼 막연한 격려만 있으면 조언 아님이다.

## §4. 오류 코드 (변환 오류·오류 주입 시트 공통)

여러 개를 고를 수 있다. 하나도 없으면 "오류 없음"을 고른다.

\* = 심각한 오류(점검이 막아야 함). † = 판단 여지를 줄이는 변형.

| 코드 | 이름 | 정의 |
|---|---|---|
| addition * † | 의미 추가 | 원문에 없는 조언·행동 제안·근거·사실·**위로·평가**를 넣음. 변환 규칙으로 붙인 상황절은 제외 |
| reversal * | 반전 | 원문의 뜻이 반대로 바뀜 (부정↔긍정, 해 봐↔하지 마) |
| new_obligation * † | 새 당위 | 원문의 제안·허용을 의무·금지로 바꾸거나, 원문에 없던 "해야 한다"를 만듦. 원문 당위를 같은 강도로 옮긴 것은 제외 |
| choice_removal * † | 선택·유보 삭제 | 원문의 조건·예외·"안 해도 된다"·대안을 빼서 선택지를 좁힘 |
| false_commitment * † | 결심·동의 생성 | 사용자가 하지 않은 결심·약속·동의를 "나는 ~하기로 했다"처럼 만듦. 일인칭으로 바꾼 것 자체는 제외 |
| distortion | 왜곡 | 반대는 아니지만 다른 의미로 바뀜 |
| omission | 누락 | 원문의 핵심 내용 일부가 빠짐. 조건·선택지를 뺀 것은 '선택·유보 삭제'로 코딩 |
| intensity_up † | 정도 강화 | 같은 행동·주장의 **정도만** 강해짐 (가끔→자주, 조금→많이). 제안→의무는 '새 당위' |
| intensity_down | 정도 약화 | 같은 행동·주장의 정도만 약해짐 (항상→가끔, 해야 해→해 봐도 돼) |
| overgeneral | 과도한 일반화 | 상황절을 넘어 주절의 범위를 지나치게 넓힘 ("이번 시험" → "모든 일") |

## §5. 헷갈리기 쉬운 구분 (판정 순서)

1. **반대 뜻인가?** 그렇다면 → 반전.
2. **선택지가 좁아졌나?** 다음 순서로 확인한다.
   - 제안·허용이 의무·금지가 됐다 → 새 당위. 정도 강화가 아니다.
   - 조건·예외·대안이 빠졌다 → 선택·유보 삭제. 누락이 아니다.
   - "하기로 했다", "그렇게 하겠다"가 생겼다 → 결심·동의 생성.
3. **원문에 없는 것이 들어왔나?** 그렇다면 → 의미 추가. 위로("나는 충분히 잘하고 있다")와 평가("좋은 방법이다")도 여기에 넣는다. 단, "비슷한 상황에서" 같은 상황절은 추가가 아니다.
4. **같은 행동의 정도만 바뀌었나?** 강해졌으면 → 정도 강화, 약해졌으면 → 정도 약화.
5. **범위가 넓어졌나?** 그렇다면 → 과도한 일반화.
6. 그 밖에 뜻이 달라졌으면 → 왜곡. 핵심 내용이 빠졌으면 → 누락.

## §6. 원문에 이미 당위가 있을 때

원문이 "무조건 네 페이스대로 해야 돼"라면, "나는 무조건 내 페이스대로 해야 한다"는 **오류 없음**이다. 같은 강도로 옮긴 것이기 때문이다. 이때 "무조건"을 빼면 정도 약화로 코딩한다.

## §7. 반문

원문 "정말 뭘 해도 안 됐어? 잘 된 적도 있지 않아?"를 "나도 잘 된 적이 있었을 수 있다"로 옮기면 오류 없음이다(완곡함 유지). 반면 "나는 잘 된 적이 있다"로 단정하면 정도 강화로 코딩한다.

## §8. 오류 주입 문장을 판정할 때

주입 유형은 숨겨져 있다. 다른 시트와 똑같이 원문과 비교해 보이는 오류를 모두 고른다. 주입 문장에 의도와 다른 오류가 들어갔을 수 있는데, 그것도 그대로 코딩한다. 이 판정이 주입 타당도이며, 점검을 평가할 때의 정답이 된다.

## §9. 연습·고정·합의 절차

1. 두 코더가 이 문서를 읽고, 파일럿 실행에서 나온 10항목을 각자 판정한다.
2. 함께 불일치를 보고 정의나 예시를 고친다. 이때 `criteria.json`과 이 문서를 같이 고친다.
3. 기준을 고정한다(버전 표시). 고정한 뒤에는 본 실행이 끝날 때까지 바꾸지 않는다.
4. 본 실행 항목을 각자 독립적으로 판정한다. 대시보드 '코딩' 탭에서 코더 1·코더 2를 각각 고른다.
5. '합의' 화면에서 다르게 본 항목만 함께 정한다. 결과에는 두 코더가 일치했거나 합의한 판정만 들어간다. 1명만 판정한 항목은 "판정 대기"로 빠진다.
6. 합의 전 코더 1·2의 판정으로 일치도(유형별 일치율·κ)를 보고한다.

## §10. 최소 대비 예시 (연습용 초안)

같은 원문에서 한 군데만 다르게 바꾼 쌍이다. 무엇이 코드를 가르는지 본다.

| # | 원문 조언 | 변환문 | 코드 |
|---|---|---|---|
| 1a | 부담되면 다음 시험부터 해도 돼. | 비슷한 상황에서 부담되면 나는 다음부터 해도 된다. | 오류 없음 |
| 1b | 〃 | 비슷한 상황에서 나는 다음부터 한다. | 선택·유보 삭제 * |
| 2a | 틀린 문제를 다시 보는 것도 방법이야. | 나는 틀린 문제를 다시 보는 것도 방법이다. | 오류 없음 |
| 2b | 〃 | 나는 틀린 문제를 다시 봐야 한다. | 새 당위 * |
| 3a | 가끔은 쉬어도 돼. | 나는 가끔은 쉬어도 된다. | 오류 없음 |
| 3b | 〃 | 나는 자주 쉬어도 된다. | 정도 강화 † (통과) |
| 4a | 이번 결과 하나로 너를 판단하지 마. | 이번 결과 하나로 나를 판단하지 말자. | 오류 없음 |
| 4b | 〃 | 나는 이번 결과 하나로 나를 판단하지 않기로 했다. | 결심·동의 생성 * |
| 5a | 공부 방법을 조금 바꿔 봐. | 나는 공부 방법을 조금 바꿔 볼 수 있다. | 오류 없음 |
| 5b | 〃 | 나는 공부 방법을 조금 바꿔 볼 수 있다. 나는 충분히 잘하고 있다. | 의미 추가 * (위로 추가) |
| 6a | 무조건 네 페이스대로 해야 돼. | 나는 무조건 내 페이스대로 해야 한다. | 오류 없음 (원문 당위 유지) |
| 6b | 〃 | 나는 내 페이스대로 해 볼 수 있다. | 정도 약화 |
| 7a | 지난 학기랑 이번은 다른 일이야. | 비슷한 상황에서 지난 일과 이번 일은 다른 일이다. | 오류 없음 |
| 7b | 〃 | 지난 일과 이번 일은 같은 일이다. | 반전 * |
| 8a | 이번 시험 하나로 너를 정하지 마. | 비슷한 상황에서 한 번의 결과로 나를 정하지 말자. | 오류 없음 (상황절) |
| 8b | 〃 | 어떤 일에서든 결과로 나를 정하지 말자. | 과도한 일반화 (통과) |
